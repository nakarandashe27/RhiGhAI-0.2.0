RhiGhAI 0.2.2 — установка для Rhino 8 / Windows x64

1. Полностью распакуйте ZIP в обычную папку.
2. Закройте все окна Rhino. Установщик проверяет это перед заменой файлов.
3. Запустите «Install RhiGhAI.cmd» под обычным пользователем Windows.
4. Запустите Rhino 8, введите команду RhiGhAI. В шапке проверьте v0.2.2.
5. «Настройки» → «Обновить»: существующий вход ChatGPT используется автоматически.
   При отсутствии входа нажмите «Войти в ChatGPT» и завершите вход в браузере.
6. Выберите модель и reasoning в панели. Выбор сохраняется автоматически.
   Каталог определяется runtime и аккаунтом. Платный API сам не включается.
   Вместо подписки ChatGPT можно использовать свой ключ: «Настройки» →
   «Провайдер модели» → «API-ключ», заполните адрес API, ключ и модель.

Стабильный путь установки:
%APPDATA%\McNeel\Rhinoceros\8.0\Plug-ins\RhiGhAI

Прошлая установка целиком сохраняется в:
%LOCALAPPDATA%\RhiGhAI\InstallBackups\<дата-и-id>
Если копирование или регистрация не завершатся, установщик восстановит её.
Авторизация Codex, история и модели пользователя не удаляются.

Откат: закройте Rhino, переместите текущую папку RhiGhAI в отдельную резервную
папку, скопируйте содержимое выбранной InstallBackups обратно в стабильный путь.
Через PlugInManager → Install выберите .rhp именно в стабильной папке.

Ручная установка: с закрытым Rhino скопируйте всю папку Payload\RhiGhAI
в стабильный путь, сохранив предыдущую установку. Откройте PlugInManager →
Install и выберите скопированный RhiGhAI.Rhino.rhp. Не выбирайте файл из ZIP
или временной папки — иначе Rhino продолжит загружать его оттуда.

Права администратора и программирование не нужны. Не отключайте защиту Windows.
API-ключ нужен только для выбранного вручную отдельного API-провайдера.
Личный тестовый плагин RhiGhAI не подписан; включённый Codex подписан OpenAI.

Проверку Undo и Grasshopper выполняйте сначала в отдельном пустом документе.
Только Windows x64 и Rhino 8 (8.20+). Некоммерческий личный проект.
Исходный код и вопросы: https://github.com/nakarandashe27/RhiGhAI-0.2.0
