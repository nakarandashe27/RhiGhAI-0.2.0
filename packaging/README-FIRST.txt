RhiGhAI 0.2.0 — локальная установка для Rhino 8 / Windows x64

1. Полностью распакуйте ZIP в обычную папку.
2. Полностью закройте Rhino. Установщик остановится, если Rhino.exe ещё работает.
3. Дважды щёлкните «Install RhiGhAI.cmd».
4. Снова запустите Rhino 8.
5. В командной строке Rhino введите: RhiGhAI
6. В шапке панели должно быть написано v0.2.0. Если там старая версия —
   установщик не отработал; см. пункт про PlugInManager ниже.
7. RhiGhAI сам подключит включённый Codex runtime. Если вход ещё не выполнен,
   откройте «Настройки» и нажмите «Войти в ChatGPT».
8. Либо вместо Codex: «Настройки» -> «Провайдер модели» -> «API-ключ»,
   вписать адрес API, ключ и модель.

Установщик кладёт файлы в один и тот же путь при любом обновлении и удаляет
папки прошлых версий: раньше рядом оставались .rhp с одним и тем же GUID,
и Rhino продолжал грузить старую сборку.

Права администратора не требуются; API-ключ нужен только если вы выбираете
API-провайдера вместо Codex. Файлы устанавливаются только для текущего
пользователя в папку плагинов Rhino 8 внутри %APPDATA%.

Если Windows блокирует запуск локального .cmd-файла, не отключайте защиту.
Вместо этого установите вручную: в Rhino откройте PlugInManager, нажмите Install
и выберите Payload\RhiGhAI\RhiGhAI.Rhino.rhp.

Проект личный, некоммерческий, тестовый и не подписан цифровой подписью.
