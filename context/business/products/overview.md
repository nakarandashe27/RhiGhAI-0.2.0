# Продукт

RhiGhAI — один локальный плагин для Windows x64 и Rhino 8.20+. В нативной Eto-панели пользователь описывает задачу обычным языком, выбирает Rhino или Grasshopper и получает контролируемое действие через свой аккаунт ChatGPT без API-ключа.

Личный MVP доказывает три workflow: создать панель с корректными единицами/слоем, изменить только выделенную геометрию одним Undo и создать сохраняемый параметрический ряд колонн. Полная формулировка обещания находится в [рабочем пресс-релизе](../../architecture/01-обзор/пресс-релиз.md).
