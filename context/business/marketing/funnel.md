# Воронка

Коммерческой воронки нет. До Yak используется продуктовая последовательность доказательств:

1. Context и architecture завершены.
2. Три blocker-gates пройдены.
3. Три acceptance workflows пройдены.
4. 30 реальных задач записаны.
5. Repeat-use и time-to-correct подтверждают ценность.
6. Competitive/signing/legal go/no-go разрешает public Yak.

Текущих конверсий и LIVE values нет. Переход к обычной воронке discovery → install → login → first success → retained use возможен после публичного релиза.

Связано: [KPI](../goals/kpi.md), [channels](channels.md), [annual goal](../goals/annual.md).
