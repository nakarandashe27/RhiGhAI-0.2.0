# Ценности

## Контроль вместо магии

Codex предлагает TaskPlan, но документ меняет только deterministic validator/executor.

## Обратимость как часть результата

Успешный ответ равен одному host Undo; неудачная попытка не оставляет изменений.

## Честная прозрачность

Пользователь видит target, стадии, C#-представление, ошибки, ограничения и фактический итог без обещаний инженерной корректности.

## Редактируемость

Rhino-результат остаётся native geometry, Grasshopper-результат — живым parameterized component.

## Малое, но доказанное

Новая capability появляется только полным вертикальным срезом schema/validator/executor/renderer/tests. First run и совместимость считаются частью продукта.
