# Brand guidelines

## Визуальный язык

Стиль «Арт.Бродский / Старт», адаптированный к нативной Eto-панели.

### Цвета

- Dark: #262626.
- Ink: #161010.
- White: #FFFFFF.
- Section/Input: #F7F7F7 / #F6F6F6.
- Primary CTA: #4D61F4.
- Stop/Error: #F74C2E.
- Accent: #F28D05 / #FF8562.
- Success accent: #D0E97E с тёмным текстом.

### Шрифты

- Заголовки: AdvakenSans-Expanded, UPPERCASE.
- UI text: Inter Tight 300/400/600.
- Code/error: Cascadia Mono или Consolas.
- Runtime CDN запрещён; desktop asset включается только при подтверждённой лицензии, иначе системный fallback.

### Компоненты

Dark shell/footer, light message rail, machine tags, borderless input, blue Send pill, red-orange Stop, минимальные тени/движение и сохранённый keyboard focus.

Полный контракт: [interface style](../../idea/06-principles/interface-style.md).

## Тон

Профессиональный, короткий, на «вы»; status сообщает факт, error — причину и состояние документа. Технический тон: [характер](../../architecture/02-ядро/характер.md).
