# Бизнес-контекст проекта

## RhiGhAI

Личный некоммерческий Rhino 8-плагин, который через ChatGPT/Codex превращает обычный язык в контролируемые Rhino operations или живой Grasshopper component без API-ключа.

При работе читай только нужный файл, не загружай всё сразу.
