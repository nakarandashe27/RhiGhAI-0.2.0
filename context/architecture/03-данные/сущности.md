# Сущности

В системе нет реляционной БД: persistent records хранятся в versioned JSON/JSONL. ER-связи ниже задают logical ownership и должны сохраняться независимо от физического формата.

Статус всех сущностей таблицы: 🔜 запланировано.

| Сущность | Назначение | Основные поля | Связи |
|---|---|---|---|
| DocumentBinding | Локально идентифицировать рабочий документ | documentKey, canonicalPath, fileFingerprint, lastRuntimeSerial, ambiguityState | active Conversation, OwnedBinding |
| Conversation | Область диалога и ownership | conversationId, documentKey, codexThreadId, status, createdAt, lastTurnId | DocumentBinding, Turns, optional GH component |
| Turn | Один пользовательский запрос | turnId, conversationId, targetHost, promptHash, model, effort, timeout, state, startedAt | Attempts, Events, Result |
| Attempt | Одна генерация/repair | attemptId, turnId, number, snapshotId, codexTurnId, planHash, errorCode, state | Snapshot, TaskPlan, CommitJournal |
| EventEnvelope | Append-only история lifecycle | eventId, correlationId, documentKey, conversationId, turnId, attemptNo, kind, timestamp, status, redactedPayload | Turn/Attempt |
| ContextSnapshot | Свежий минимальный model context | snapshotId, documentIdentity, host, units, tolerances, layers, selection, ownedRefs, capturedAt | Fingerprints, Attempt |
| ModelReference | Разрешённая ссылка на host object | referenceId, host, objectId, objectType, accessOrigin selection/owned | Snapshot, Fingerprint, OperationNode |
| Fingerprint | Защита от stale/TOCTOU | referenceId, documentRuntimeId, geometrySignature, attributesSignature, layerId, selectionState | ModelReference |

| AccountSnapshot | Только UI-состояние, не credentials | authMode, displayLabel, planType, rateLimit summary, refreshedAt | Codex Adapter |

## Два главных кирпича

- **OperationNode** унифицирует вычисления, validation, rendering и execution.
- **EventEnvelope** унифицирует progress, transcript, diagnostics и recovery.

Остальные сущности остаются типизированными и не превращаются в property bags.
