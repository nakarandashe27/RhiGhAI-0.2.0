# RhiGhAI

## Опишите изменение — получите управляемый результат в Rhino или Grasshopper

## Дата запуска: август 2026, сразу после прохождения обязательных технических gate

## Главный абзац

RhiGhAI — встроенная панель для Rhino 8, в которой можно обычными словами попросить создать или изменить модель. Она подходит моделировщику, который знает Rhino, но не хочет писать скрипты и разбираться в API. Пользователь остаётся в открытом документе, видит ход работы и представление выполненного плана, а результат целиком отменяется одним Ctrl-Z. Для параметрических задач RhiGhAI создаёт живой компонент Grasshopper с понятными входами.

## Проблема

Даже простая автоматизация в Rhino требует знания команд, RhinoCommon, C#, Python или устройства Grasshopper-графа. Обычный AI может написать код, но не знает актуального выделения, единиц и слоёв, а ошибка способна оставить модель частично изменённой.

## Решение

RhiGhAI подключается к Codex через аккаунт ChatGPT без API-ключа. Codex не получает право выполнять произвольный код: он возвращает строгий план из разрешённых операций, а плагин проверяет его, сверяет с текущим документом и применяет короткой транзакцией только в выбранной среде — Rhino либо Grasshopper. Неудачная попытка откатывается, диагностируется и может быть автоматически исправлена в пределах заданного лимита.

## Цитата основателя

«AI должен ускорять моделирование, не заставляя выбирать между магией и контролем. В RhiGhAI модель предлагает решение, но право изменить документ остаётся у проверяемого исполнителя».

## Как начать пользоваться

1. Установить RhiGhAI и открыть его панель в Rhino 8.
2. В настройках проверить Codex и войти в аккаунт ChatGPT; если runtime отсутствует, установить проверенную версию одной явной кнопкой.
3. Выбрать Rhino или Grasshopper, описать задачу и нажать «Отправить».

## Цитата клиента

«Я попросил сделать параметрический ряд колонн, получил один понятный компонент с Count, Spacing, Height и Radius, поменял значения и сразу увидел новый вариант. Мне не пришлось писать код или собирать граф вручную».

## Призыв к действию

Откройте RhiGhAI рядом с моделью, выберите среду и опишите следующее изменение обычными словами.

## Внутренние вопросы

- **Какая экономика?** Личный MVP не имеет собственной подписки, сервера и биллинга; доступность Codex определяется аккаунтом ChatGPT пользователя. Публичная модель появится только после технической проверки.
- **Какие три самых больших риска?** Experimental Codex app-server, нарушение атомарности Undo/rollback и несохраняемый динамический Grasshopper-компонент.
- **Что мы не делаем в первой версии?** Произвольный C#/Python, Mesh, SubD, материалы, рендеринг, layouts, blocks, Data Trees и одновременное изменение Rhino с Grasshopper.
- **От чего зависим?** От Rhino 8/Grasshopper 1 на Windows x64, RhinoCommon/Eto/GH SDK и закреплённой официальной версии Codex runtime с ChatGPT OAuth.
- **Как поймём, что провалились?** Три приёмочных сценария медленнее ручной работы, неудача оставляет изменения, успешный ответ требует больше одного Undo либо first run требует терминала/API-ключа.

## Внешние вопросы

- **Чем отличается от существующих решений?** Не просто чатом, а типизированным планом, selection/ownership policy, проверкой актуальности документа, одним Undo и полным rollback каждой неудачной попытки.
- **Что с моими данными?** Полная модель остаётся в Rhino. Codex получает промпт и минимальный структурированный snapshot; учётные данные хранит официальный runtime, а thread id не записывается в файл 3dm.
- **Сколько стоит?** В личном MVP отдельной платы RhiGhAI нет; необходим доступный пользователю аккаунт ChatGPT/Codex, его лимиты и условия действуют отдельно.
- **Что делать, если система ошибётся?** Неудачная попытка автоматически откатывается и может быть исправлена до заданного лимита. Успешный, но нежелательный результат отменяется одним Ctrl-Z.
- **Как связаться с создателем?** Для личного MVP поддержка ведётся напрямую владельцем проекта; канал публичной поддержки определяется перед Yak-релизом.
