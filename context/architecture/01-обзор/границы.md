# Границы

## Что внутри системы

- RHP/GHA assemblies и одна Eto-панель.
- Внутренние контракты TaskPlan (Rhino) и GhGraph (Grasshopper), их schema и semantic validation.
- Capability registry, canonical operation graph и C#-представление.
- Сбор минимального snapshot и fingerprint.
- Выбор провайдера модели (Codex или OpenAI-совместимый API), оркестрация turn, retries, timeout и cancellation.
- Каталог компонентов установленного Grasshopper и эмиссия native-графа на холст.
- Хранение API-ключа провайдера, зашифрованного DPAPI для текущего пользователя Windows.
- Rhino/GH prepare, commit, undo/rollback и fault-safe journal.
- Локальные settings, document↔thread mapping, transcript и redacted diagnostics.
- Установка, проверка и lifecycle закреплённого Codex runtime.

## Что снаружи

- Rhino 8, RhinoCommon, Eto, Grasshopper 1 и их Undo API.
- Официальный Codex app-server и его ChatGPT OAuth/model entitlement.
- Сторонние OpenAI-совместимые API и их каталоги моделей, тарифы и лимиты.
- Компоненты Grasshopper, включая сторонние плагины пользователя, и их собственное поведение.
- Windows, браузер входа, TLS, файловая система профиля и Defender/SmartScreen.
- Содержимое открытых Rhino/GH документов и действия пользователя во время ожидания.

## Граница доверия

### Приходит от пользователя и документа — недоверенное

- Prompt, имена слоёв/объектов, user strings и текстовые GH inputs могут быть ошибочными или содержать инструктивный текст.
- Selection разрешает область возможного изменения, но не доказывает корректность намерения.
- Любые ссылки на GUID проверяются против свежего документа, target host и fingerprint.
- Критическая неоднозначность units, axes, plane или target приводит к уточняющему вопросу, а не к догадке.

### Приходит от провайдера модели — всегда недоверенное

- Не важно, Codex это или сторонний API по ключу: даже schema-valid TaskPlan или GhGraph проходит semantic validation, capability policy, complexity budgets и stale check.
- Компонент, которого нет в живом каталоге установки, и порт с неверным именем отклоняются до эмиссии.
- Script-компоненты Grasshopper исключены из каталога, поэтому план не может выполнить произвольный код.
- Модель не получает filesystem/network/process/Rhino tools и не выполняет показанный C#.
- Неизвестная версия plan, operation или field отклоняется fail-closed.

### Внешние API — доверяем контракту, но ожидаем сбой

- Провайдер может быть недоступен, разлогинен, ограничен usage limit, отклонить ключ или не поддержать strict json_schema.
- RhinoCommon/GH calls могут вернуть null, failure или занять UI thread; каждый результат проверяется.
- Сбой браузера OAuth или Defender не обходится небезопасной установкой.

### Полностью доверяем

- Подписанным assemblies RhiGhAI.
- Встроенным versioned schemas, operation registry, SHA manifest и заранее проверенным protocol fixtures.
- Данным, построенным ядром после всех validation stages, только до следующей проверки актуальности.

## Физические границы MVP

Один процесс Rhino, загруженные RHP/GHA и — в зависимости от провайдера — либо один дочерний Codex process по stdio, либо исходящий HTTPS к выбранному API. Нет loopback HTTP-сервера, MCP-router, Python bridge, удалённой базы, фонового сервиса Windows или микросервисов.
