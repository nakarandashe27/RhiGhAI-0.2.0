# Карта системы

RhiGhAI — один локальный .NET-плагин с двумя host-адаптерами и одним управляемым дочерним процессом Codex. Собственного сервера, базы данных и облачного деплоя нет.

## Компоненты

- **Eto panel/ViewModel** — единственный пользовательский экран; не содержит моделирующей логики.
- **Turn Orchestrator** — конечный автомат одного запроса: snapshot → generation → validation → prepare → commit либо repair/stop.
- **Codex Adapter** — единственное место, знающее experimental protocol; остальное ядро зависит от стабильного внутреннего интерфейса.
- **Capability Registry** — allowlist операций, где каждая способность поставляется вертикальным срезом validator/executor/renderer/tests.
- **Canonical Operation Graph** — единое проверенное представление между TaskPlan и обоими исполнителями.
- **Commit Coordinator** — проверяет fingerprint непосредственно перед commit, открывает один host Undo record и ведёт journal.
- **Rhino/GH Executors** — отдельные адаптеры; один turn вызывает ровно один.
- **Conversation Store** — локальная связь документа с Codex thread и UI transcript; не пишет thread id в 3dm.
- **Runtime Manager** — ставит только явно запрошенный pinned Codex asset, проверяет SHA и запускает его без PATH.

## UX-стиль

Это визуальный инструмент: в панели постоянно видны target, selection, поток стадий, код-представление, ошибки и итог. Движение минимально и не блокирует работу; визуальный контракт описан в [стиле интерфейса](../../idea/06-principles/interface-style.md).
