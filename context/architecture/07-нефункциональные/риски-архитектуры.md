# Pre-mortem архитектуры RhiGhAI

Прошёл год. Архитектуру переписывали с нуля, потому что ключевые гарантии остались формулировками вместо проверяемых протоколов.

## 3 убийственных риска

### 1. Закреплённый Codex runtime перестал подключаться к ChatGPT

**Что сломалось.** Binary запускался, но server-side OAuth, entitlement, model catalog или event format изменились, и пользователь не мог начать turn.

**Почему здесь.** [Стек](../05-стек/технологии.md) изолировал app-server и SHA-pin, но pin не защищает от серверной несовместимости. [Управление Codex](../02-ядро/способности/управлять-codex.md) не определяло negotiated capabilities и plugin/runtime/server matrix.

**Что сделать сейчас.** Добавить контракт совместимости: точные versions/schema hash, обязательные methods/events, feature negotiation, recorded fixtures и last-known-good. Startup/install gate обязан пройти initialize → account/read → model/list → thread start/resume → outputSchema turn → stream → interrupt на чистой Windows.

### 2. Один Undo оказался не транзакцией

**Что сломалось.** Исключение оставило слой и часть geometry, а после crash нельзя было доказать, что верхний Undo принадлежит RhiGhAI.

**Почему здесь.** [Инварианты](../03-данные/правила-нерушимые.md#host-и-транзакции) обещали before-state equivalence, но [CommitJournal](../03-данные/сущности.md) не содержал полного compensation protocol.

**Что сделать сейчас.** Формализовать durable prepared journal → fresh fingerprint → cancellation barrier → BeginUndo → mutations → postconditions → EndUndo → verified result → ownership. Rollback допускается только внутри того же UI callback и при подтверждённом собственном Undo identity. Crash даёт blocking uncertain state, не blind Undo. Fault/crash injection — после каждой mutation.

### 3. RhiGhAI Parametric разрушал GH definition

**Что сломалось.** Rename/reorder/type change/remove ports теряли wires; Undo не восстанавливал внешние связи, а новая GHA не читала старый state.

**Почему здесь.** [Capability](../02-ядро/способности/определение-grasshopper.md) полагалась на stable portId, не определив связь с GH parameter instances и допустимые migrations.

**Что сделать сейчас.** Определить port protocol, connected-port policy, wire snapshot, solution suspension, restore/post-solve verification и отдельные версии algorithm/component/ports. Gate: 8.20 + current, save/reopen, upgrade, copy/paste, duplicate, Undo/Redo, wires, item/list, missing references и solve exceptions.

## 5 серьёзных рисков

### 4. Stop/timeout и поздний event запустили commit

**Что сломалось.** Terminal turn получил late plan/Idle callback и применил geometry либо rollback другого attempt.

**Почему здесь.** [State machine](../04-потоки/триггеры.md#turn-state-machine) не имела полной state × event table, absorbing states, epoch и commit lease.

**Что сделать сейчас.** Один serialized reducer на document, monotonically increasing attempt epoch, one-shot commit lease, terminal states absorbing, точка невозврата и exhaustive race permutations.

### 5. Save As/Copy продолжили чужой разговор

**Что сломалось.** Original, copy и recovery получили один thread/ownership.

**Почему здесь.** [Память](../02-ядро/память-и-состояние.md) использовала path/fingerprint/runtime serial без identity state machine.

**Что сделать сейчас.** Состояния Unsaved/Open/Saving/SavedAs/ExternallyCopied/Recovered/Missing/Ambiguous и матрица New/Open/Save/Save As/Rename/Copy/Recovery/multi-process. Внешняя копия без embedded id всегда начинает новый conversation.

### 6. Строгие DTO стали несовместимы сами с собой

**Что сломалось.** Optional external field ломал transport, а TaskPlan/GH state не имели последовательной migration.

**Почему здесь.** [Стек JSON](../05-стек/технологии.md) применял одну strictness к evolving app-server envelopes и security-critical TaskPlan.

**Что сделать сейчас.** Tolerant version-specific outer reader с method/event allowlist; строгий TaskPlan union; независимые версии graph/event/component. Поддержка read N/N-1 → sequential migrate → write current, quarantine unknown future, golden corpus.

### 7. Operation graph был недетерминирован

**Что сломалось.** Одинаковый plan давал разные graphHash, Boolean order и C# representation.

**Почему здесь.** [OperationNode](../03-данные/главный-кирпич.md) не зафиксировал ordering, defaults, number/unit normalization и capability version.

**Что сделать сейчас.** Canonical JSON, stable topological sort, no implicit defaults, invariant numbers, registry version, deterministic native output ordering. Один immutable graph читают validator/renderer/executor; golden parity tests обязательны.

### 8. Опасная тройка AI осталась открытой

**Что сломалось.** Prompt injection в layer/object/GH text повлиял на allowlisted plan и локальное действие.

**Почему здесь.** Есть personal model data, untrusted content и отправка наружу; [граница](../01-обзор/границы.md) признавала это, но snapshot не разделял instructions и literal data.

**Что сделать сейчас.** Codex — читающий агент без tools; executor — действующий и получает только validated plan. Field-origin tags, отдельные instruction/data fields, control-character normalization, no user strings by default, literal quoting и adversarial fixtures.

## Остальные заметки

### 9. LocalAppData потерял mapping и journal

**Что сломалось.** Два Rhino processes сделали lost update, JSONL перемешался, runtime manifest указал на partial directory.

**Почему здесь.** [Persistence](../05-стек/технологии.md) обещала atomic replace без multi-process locking и разных durability classes.

**Что сделать сейчас.** Отдельные stores, immutable runtime dirs, user-scoped mutex/file locks, checksum/header, flush + replace + backup и class-specific recovery. Corrupt committing journal блокирует новые commits.

### 10. First run заблокировали Defender/SmartScreen

**Что сломалось.** Unsigned RHP/GHA и executable в LocalAppData попали в quarantine.

**Почему здесь.** [Packaging](../05-стек/технологии.md) считал SHA достаточным, хотя он не создаёт Windows publisher trust и не решает Mark-of-the-Web.

**Что сделать сейчас.** Installation trust chain: source/license, signed manifest, Authenticode installer/assemblies, publisher + SHA, immutable activation/rollback и безопасная диагностика без обхода Defender. Clean Windows standard-user matrix становится release gate.

## Вердикт

Вариант B OperationNode + EventEnvelope менять не нужно. Feature-разработка после минимального каркаса должна остановиться до трёх blocker-spikes:

1. Codex runtime/auth/protocol compatibility;
2. Rhino commit/Undo/journal fault and crash injection;
3. Grasshopper round-trip/ports/Undo/solve.

После них обязательны race reducer, document identity machine, независимое versioning, canonical graph, dangerous-triad separation, LocalAppData locking и installation trust chain. Без этих протоколов слова «без мусора», «один Ctrl-Z», «Stop» и «продолжить после перезапуска» не являются архитектурной гарантией.
