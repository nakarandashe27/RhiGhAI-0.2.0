# ADR-002 — OperationNode + EventEnvelope

- **Дата:** 2026-08-24
- **Статус:** принято пользователем
- **Решение:** OperationNode представляет вычисление, EventEnvelope — lifecycle/history; остальные records остаются типизированными.
- **Причина:** один universal object размывает safety types, полное разделение дублирует pipelines.
- **Последствия:** независимые graph/event schemas и migrations.
