# ADR-003 — Один host на turn

- **Дата:** 2026-08-24
- **Статус:** принято
- **Решение:** ответ меняет Rhino либо Grasshopper, никогда оба; Bake — отдельный explicit Rhino action.
- **Причина:** Undo stacks независимы, общей atomic transaction нет.
- **Последствия:** target выбирается до Send; mixed-host plan отклоняется.
