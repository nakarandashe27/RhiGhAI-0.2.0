# ADR-001 — TaskPlan вместо произвольного кода

- **Дата:** 2026-08-24
- **Статус:** принято
- **Решение:** Codex возвращает strict TaskPlan; C# только отображается; host меняет deterministic executor.
- **Причина:** произвольный код нельзя надёжно ограничить, остановить и целиком откатить.
- **Последствия:** каждая capability требует полного validator/executor/renderer/test vertical slice.
