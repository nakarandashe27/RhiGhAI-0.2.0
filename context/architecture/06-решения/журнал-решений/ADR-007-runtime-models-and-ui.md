# ADR-007 — runtime, каталог моделей и нативные controls

Дата: 2026-10-03. Статус: принято для 0.2.1.

Codex остаётся провайдером с общей авторизацией Desktop/CLI. Refresh прекращает дочерний app-server, выбирает самый новый проверенный подписанный локальный binary, атомарно обновляет Current и запускает клиент заново. Предыдущий binary сохраняется; ошибка запуска нового возвращает предыдущий. Версия сравнивается численно, копирование и проверка подписи идут вне UI. Сеть для установки runtime не используется. Нельзя менять runtime во время turn.

model/list читается до nextCursor=null, hidden исключаются, model slug служит ID запросов; legacy каталог без model использует id. Дубликаты объединяются по slug, efforts берутся только из ответа. Пустой/несовместимый каталог не даёт отправить запрос. Каталог не доказывает entitlement: реальные успешные запросы перечислены в [TEST_REPORT.md](../../../../TEST_REPORT.md).

Stateless в обоих провайдерах исключает историю. У Codex для него создаётся отдельный ephemeral thread; сохранённый Rhino thread не меняется. GH follow-up заменяет прошлый native граф того же живого документа/диалога, но словесную историю не воспроизводит — новый запрос должен быть самодостаточным. Stop/timeout прерывают конкретный thread/turn; события чужих turns игнорируются.

При commit проверяется исходный живой GH документ и Rhino snapshot, включая Save As. GH использует одну собственную запись Undo по GUID; отсутствие собственной записи Undo запрещает mutation (MaxRecords=0 в проверенном host не отключает Undo). Ownership публикуется после проверки solution. При неудаче Undo выполняется для конкретной записи, не для последнего действия пользователя.

Кнопки — нативные Eto Button с WPF template: радиус 8, keyboard focus, Automation button role, стандартный Tab/Enter/Space. Палитра нейтральная, основной акцент синий, Segoe UI/Consolas. Структура панели и отдельный диалог настроек сохраняются. Приёмка DPI и настоящего dock UI учитывается отдельно от unit-тестов.

Установщик проверяет целостность и подпись runtime, делает staging, сохраняет старую установку целиком и восстанавливает её при ошибке. GUID и стабильный путь прежние.

Native GH Undo/Redo содержит отдельный ownership action: восстановленные GUIDs принадлежат той же области диалога. Forget запрещает Undo повторно захватывать освобождённую область. Это устраняет воспроизведённое дублирование после Undo.
