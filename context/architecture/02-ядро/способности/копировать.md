# Способность: копировать геометрию

## Когда применять

Создать ограниченное число копий выделенных или RhiGhAI-owned Rhino objects по явным transforms.

## Когда НЕ применять

Не копировать hidden/locked/unselected объекты, block definitions и сотни экземпляров.

## Примеры

- Good: сделать пять копий выделенной кривой с шагом 300 мм.
- Bad: размножить объект до заполнения всей модели без указанного лимита.

## Что может пойти не так

Count отрицательный/слишком большой, transform invalid или target stale. Validator ограничивает count и итоговое число объектов; все новые GUID записываются в journal и ownership только после commit.
