# Способность: создать слой

## Когда применять

Создать отсутствующий Rhino layer, который явно назван в запросе или нужен другой операции того же Rhino turn.

## Когда НЕ применять

Не переименовывать, удалять и не менять существующий layer tree. Не создавать слой в Grasshopper turn.

## Примеры

- Good: создать слой Panels перед добавлением панели.
- Bad: удалить все пустые слои — destructive operation вне MVP.

## Что может пойти не так

Имя пустое/недопустимое, слой уже существует или документ стал stale. Existing layer разрешается идемпотентно по точному full path; создание входит в тот же Rhino Undo/journal, и пустой новый слой удаляется при rollback.
