# Способность: исправить план

## Когда применять

После repairable schema/semantic/geometry error, когда попытка полностью откатана, timeout не истёк и лимит 1–5 не исчерпан.

## Когда НЕ применять

Не retry auth, entitlement/usage, cancellation, timeout, stale document, unsupported intent и повтор той же пары plan/error.

## Примеры

- Good: Codex получает свежий snapshot и error code OpenProfileNotAllowed после чистого rollback.
- Bad: пять раз отправить одинаковый plan после смены active document.

## Что может пойти не так

Модель повторяет ошибку или новая попытка устаревает. Хэш plan/error предотвращает цикл; каждый retry пересобирает snapshot; общий turn timeout не сбрасывается.
