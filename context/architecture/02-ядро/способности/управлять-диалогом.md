# Способность: управлять диалогом

## Когда применять

Создать/resume один Codex thread на active document binding; New conversation создаёт новый thread и ownership scope.

## Когда НЕ применять

Не угадывать identity после ambiguous Save As/Copy и не записывать Codex thread id в 3dm/gh.

## Примеры

- Good: после restart открыть тот же документ и resume локально связанный thread.
- Bad: продолжить историю оригинала в скопированном файле только из-за похожего имени.

## Что может пойти не так

Thread удалён/несовместим, mapping corrupted или identity ambiguous. Atomic store сохраняет предыдущую версию; создаётся новый conversation с понятным status, без переноса ownership.
