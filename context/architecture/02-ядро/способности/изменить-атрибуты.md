# Способность: изменить атрибуты

## Когда применять

Назначить layer и, при явном запросе, object name для актуально выделенных либо RhiGhAI-owned Rhino objects.

## Когда НЕ применять

Не менять материалы, render attributes, groups, visibility, locking и document properties в MVP.

## Примеры

- Good: перенести выделенные объекты на слой Raised.
- Bad: назначить всем объектам случайные материалы.

## Что может пойти не так

Layer отсутствует, object reference stale или attributes read-only. Layer может быть создан способностью создать слой в той же transaction; originals журналируются для rollback.
