# Права и автономия

Codex никогда не действует в host напрямую. Колонка Codex означает право предложить операцию в TaskPlan; RhiGhAI автоматика означает право выполнить её после всех проверок.

| Действие | Пользователь | Codex | RhiGhAI автоматика |
|---|---|---|---|
| Читать compact snapshot активного host | сам | сам | сам |
| Читать полную геометрию/файлы/сеть | запретить | запретить | запретить |
| Создать новую allowlisted Rhino geometry | сам | сам | сам |
| Изменить актуально выделенный объект по явному запросу | сам | сам | сам |
| Изменить RhiGhAI-owned объект текущего conversation | сам | сам | сам |
| Изменить существующий невыделенный/чужой объект | эскалировать | запретить | запретить |
| Удалить существующий объект | эскалировать | запретить | запретить |
| Создать/update один owned GH component | сам | сам | сам |
| Изменить произвольный GH graph | эскалировать | запретить | запретить |
| Bake GH preview в Rhino | сам | запретить | спросить |
| Выполнить произвольный C#/Python/shell | запретить | запретить | запретить |
| Начать repairable retry в заданном лимите | сам | сам | сам |
| Retry auth/usage/stop/stale/identical error | запретить | запретить | запретить |
| Install/обновить Codex runtime | сам | запретить | спросить |
| Открыть browser login | сам | запретить | спросить |
| Logout | сам | запретить | спросить |
| Создать новый conversation | сам | запретить | спросить |
| Перепривязать ambiguous Save As/Copy к старому thread | эскалировать | запретить | запретить |
| Изменить retry/timeout/settings | сам | запретить | спросить |

## Значения

- **сам** — допустимо в нормальном workflow без дополнительного modal confirmation.
- **спросить** — требуется явное нажатие пользователя; AI не может инициировать.
- **эскалировать** — действие вне MVP и требует будущего отдельного решения/UX.
- **запретить** — не обходится настройкой autonomy.

Отдельного autonomy slider в MVP нет: границы одинаковы для всех моделей и reasoning effort.
