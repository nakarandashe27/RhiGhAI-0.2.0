# Контекст RhiGhAI

RhiGhAI — личный некоммерческий плагин для Rhino 8, который через локальный Codex с входом в ChatGPT преобразует обычный язык в контролируемые операции Rhino или редактируемый параметрический компонент Grasshopper.

Это главная точка входа в контекст проекта. Перед задачей читай только подходящий раздел и документы, на которые он ссылается; не загружай весь каталог целиком.

| Раздел | Когда читать | Точка входа |
|---|---|---|
| Идея | Зачем существует продукт, кому он нужен, границы MVP, критерии успеха и исходные риски | [Идея](idea/README.md) |
| Архитектура | Контракты, компоненты, данные, безопасность, интеграции Rhino/Grasshopper/Codex и порядок реализации | [Архитектура](architecture/README.md) |
| Бизнес | Статус проекта, продукт, аудитория, цели, экономика, коммуникация и бренд | [Бизнес](business/INDEX.md) |

## Правило работы с контекстом

1. Определи текущий этап по [дорожной карте](architecture/08-дорожная-карта/roadmap.md).
2. Открой только перечисленные в этапе файлы и их прямые ссылки, необходимые для решения.
3. Не выдумывай отсутствующие продуктовые, технические или бизнес-факты; фиксируй новое решение в соответствующем разделе.
4. После завершения этапа обнови его статус и связанные проверки.
