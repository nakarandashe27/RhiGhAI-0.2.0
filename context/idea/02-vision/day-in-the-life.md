# Типичный день пользователя

Пользователь открывает существующую модель Rhino. В панели RhiGhAI видны текущий документ, единицы, слой, краткое описание выделения и состояние подключения к ChatGPT.

Для новой геометрии пользователь оставляет режим `Rhino`, пишет задачу и выбирает модель с глубиной работы. Пока Codex думает, Rhino остаётся доступным, а лента показывает этапы. После получения ответа появляется эквивалентный C# и итог применения. Если результат не подходит, один Ctrl-Z возвращает документ в предыдущее состояние.

Для параметрической задачи пользователь переключается на `Grasshopper`. RhiGhAI открывает Grasshopper при необходимости, создаёт `RhiGhAI Parametric` с понятными входами и показывает preview. Пользователь меняет sliders или подключённую геометрию и получает новый результат без повторной генерации.

Следующая реплика продолжает текущую работу. Кнопка «Начать заново» создаёт новый диалог и новый параметрический компонент.
