# RhiGhAI — замысел

RhiGhAI — локальный помощник для Rhino 8, который превращает обычный язык в контролируемые операции RhinoCommon или параметрический компонент Grasshopper, используя Codex через подписку ChatGPT без API-ключа.

## Коротко

Пользователь описывает изменение модели словами, видит ход работы и эквивалентный C#, а RhiGhAI применяет валидированный план как одну отменяемую транзакцию. Для параметрических задач тот же диалог создаёт и обновляет собственный компонент `RhiGhAI Parametric` в Grasshopper.
