# Главная сцена MVP

## Золотой момент

Пользователь пишет: «Создай параметрический ряд колонн с входами Count, Spacing, Height и Radius».

RhiGhAI открывает Grasshopper, создаёт один компонент `RhiGhAI Parametric`, добавляет типизированные входы, строит preview колонн и сохраняет алгоритм в definition. Изменение Count или Height сразу пересчитывает геометрию без повторного обращения к Codex.

## Почему это главная ценность

Это не одноразовый макрос и не картинка результата. Пользователь получает изменяемый вычислительный объект, который можно сохранить вместе с Grasshopper-документом и подключить к другой геометрии.
