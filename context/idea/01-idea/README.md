# Идея

## Супер-идея

Дать пользователю Rhino 8 возможность моделировать обычным языком через локальный Codex, не вводя API-ключ и не превращая Rhino в небезопасный исполнитель произвольного LLM-кода.

## Контекст

Rhino и Grasshopper обладают мощными программными API, но автоматизация требует знания RhinoCommon, C#, Python или устройства Grasshopper-графа. RhiGhAI переносит эту техническую работу в диалог: пользователь формулирует намерение, а система сама собирает контекст открытой модели и строит исполнимый план.

Продукт не запускает произвольный сгенерированный код. Codex возвращает типизированный план из разрешённых операций; RhiGhAI валидирует его, показывает эквивалентный C# и только затем автоматически применяет изменения на UI-потоке Rhino.

Для Grasshopper продукт создаёт один сохраняемый параметрический компонент на диалог. Его входы можно менять обычными средствами Grasshopper, а геометрия пересчитывается без повторного обращения к Codex.
