# Почему сейчас

## Что изменилось

- Codex получил локальный app-server для встраиваемых клиентов: вход через ChatGPT, потоковые события, threads, отмена turn и динамический каталог моделей.
- Rhino 8 перешёл на современный .NET и предоставляет RhinoCommon, Eto, RhinoCode и актуальный Grasshopper SDK в одной установке.
- Современные coding-модели способны выдавать структурированный результат по JSON Schema, поэтому между языковой моделью и документом можно поставить строгий валидатор.
- Пользователи уже привыкли описывать технические задачи естественным языком, но существующие терминальные агенты не знают текущего выделения, единиц и Undo-семантики Rhino.

## Окно возможности

Сейчас можно собрать локальный интерфейс, который использует существующую подписку ChatGPT и остаётся нативной частью Rhino. Главный риск — экспериментальный статус Codex app-server, поэтому интеграция должна быть изолирована адаптером и привязана к проверенной версии CLI.
