# Наша дельта

Не уникальны сами по себе: natural-language CAD, чат в Rhino, генерация Grasshopper, редактируемые результаты и каталоги AI-действий. Уникально для MVP их строгое сочетание.

| Измерение | Типичный AI-CAD copilot | RhiGhAI MVP |
|---|---|---|
| Доступ | API-ключ или отдельный SaaS | Аккаунт ChatGPT через Codex, без API-ключа |
| Исполнение | Сгенерированный код/tool calls | Типизированный allowlisted TaskPlan |
| Host | Один CAD или отдельная среда | Явно Rhino **или** Grasshopper |
| Параметрика | Часто одноразовый результат | Один живой компонент на диалог |
| Ошибки | Сообщение или ручной retry | Откат и до пяти автоматических исправлений |
| Undo | Не всегда определён | Один ответ — один Undo выбранного host |
| Конкурентность | Неявная | Fingerprint и отказ от stale plan |
| Прозрачность | Чёрный ящик | План, эквивалент C#, стадии и ошибка |
| Контекст | История чата или полный документ | Долгий thread + свежий минимальный snapshot |
| Область изменения | Широкая | Selection/ownership + семантический валидатор |

## Формула

**RhiGhAI — нативный контролируемый исполнитель намерений для Rhino 8 и Grasshopper 1: Codex предлагает строгий план, а плагин применяет только допустимые, актуальные и целиком отменяемые изменения.**

Пользовательская формулировка: **«Опишите изменение — RhiGhAI безопасно выполнит его в Rhino либо создаст живой параметрический компонент Grasshopper».**

## Что может стереть дельту

Официальный McNeel RhinoMCP уже планирует близкий UX. Поэтому moat — не panel и не чат, а TaskPlan/schema, тесты, реестр операций, ownership, транзакции, fingerprints, надёжный runtime и отточенные workflow. Это должно направлять [[../06-principles/README]] и будущую архитектуру.
