# Визуальный язык интерфейса

RhiGhAI использует стилистику «Арт.Бродский / Старт» из DESIGN_BRIEF.md как визуальный референс, адаптированный к нативной dockable Eto-панели Rhino 8. Функциональные требования и системные конвенции Windows/Rhino имеют приоритет над буквальным воспроизведением веб-страницы.

## Узнаваемые признаки

- Тёмная оболочка и нижняя status line: #262626.
- Основные рабочие поверхности: #FFFFFF и #F7F7F7; поля: #F6F6F6.
- Primary action Send: синяя пилюля #4D61F4 с белым текстом.
- Stop и критическая ошибка: #F74C2E; ссылки и мягкие акценты: #FF8562; активное слово/маркер: #F28D05.
- Успешный статус может использовать #D0E97E с тёмным текстом.
- Заголовок RhiGhAI и крупные названия секций — AdvakenSans-Expanded, UPPERCASE.
- Весь обычный интерфейс — Inter Tight 300/400/600, без капса.
- Служебные подписи оформляются как машинные метки: [ MODEL ], [ RHINO ], [ SELECTION ], ↳01.
- Ритм кратен 4 px; блоки плотные, соседние поверхности могут соприкасаться без декоративных gaps.
- Анимация только короткая: fade/сдвиг до 6 px или изменение opacity; учитывается reduced motion.

## Адаптация к панели Rhino

Вебовые display-размеры 80/48 px не переносятся буквально. В dockable panel применяется компактная шкала:

| Роль | Размер | Правило |
|---|---:|---|
| Название RhiGhAI | 24–28 px | Advaken, UPPERCASE |
| Заголовок режима/настроек | 18–22 px | Advaken, UPPERCASE |
| Текст сообщения и controls | 13–14 px | Inter Tight |
| Secondary text | 11–12 px | Inter Tight |
| Machine tag | 10–11 px | Inter Tight, UPPERCASE, tracking |
| Код и stack trace | 11–12 px | Cascadia Mono/Consolas; единственное типографическое исключение |

Рабочие карточки имеют радиус 8–12 px. Радиус 24 px и card shadow используются только для крупных всплывающих/пустых состояний: внутри плотной ленты множественные тени создают шум. Поле prompt — светлое, без рамки, с радиусом около 12–16 px. Primary Send остаётся полной синей пилюлей.

## Применение к утверждённой структуре

- **Header:** тёмный #262626, RhiGhAI капсом; New chat как ghost pill, Settings как компактная icon/button.
- **Message rail:** #F7F7F7; user/assistant/progress блоки различаются геометрией, меткой и акцентной полосой, а не множеством цветов.
- **Code/error:** отдельный тёмный или белый inset с monospace; error code выделяется #F74C2E, полный текст остаётся копируемым.
- **Selection line:** компактная машинная строка [ SELECTION ] с количеством и типами.
- **Composer:** большой #F6F6F6 prompt, под ним цель, модель и reasoning; Send — #4D61F4, во время работы Stop — #F74C2E.
- **Footer:** #262626, account и доступная статистика белым с пониженной opacity.
- **Settings:** тот же экран временно заменяет центральное содержимое; группы без отдельного окна, Save and close — primary pill.

## Что не переносится

- Фотофоны и фотоплитки: они отвлекают от модели и требуют несвязанной сети/ассетов.
- Сетка 1200 px и веб-breakpoints: вместо них используются минимальная ширина панели, DPI scaling и перенос controls.
- CDN-загрузка шрифтов: runtime плагина не зависит от Google/Tilda. Desktop font assets можно включить только при подтверждённом праве распространения; иначе используется локальный fallback Arial Narrow/Segoe UI.
- Hover scale 0.95 на рабочих кнопках: в desktop UI он меняет hit target; допускается только opacity/цвет.
- Маркетинговые 48/80 px заголовки внутри узкой рабочей панели.

## Запрещено

- Акцидентный шрифт в обычном тексте.
- Случайные цвета вне палитры или разворот фирменного градиента.
- Тяжёлые и множественные тени.
- Рамки вокруг prompt и обычных input.
- Длинные, пружинящие или блокирующие анимации.
- Снижение контраста статуса, ошибки, Stop или keyboard focus ради бренда.

## Приёмка

Интерфейс должен оставаться узнаваемым при отключённых custom fonts, в 100/125/150/200% DPI, при минимальной ширине docked panel и с клавиатурной навигацией. Цвет не является единственным носителем статуса.
