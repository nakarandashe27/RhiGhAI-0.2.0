# Визуальный язык RhiGhAI

С 0.2.1 — компактный спокойный desktop-интерфейс в направлении Apple, адаптированный к Windows/Rhino/Eto. Сохраняются имя RhiGhAI, тёмная шапка, светлая лента, отдельные настройки и прежние действия.

- Segoe UI: заголовок 15 pt bold, основной текст 10–10.5 pt, вторичные подписи 9 pt. Consolas только для кода.
- Фоны белый/#F7F7F7; тёмная оболочка #2A2D33, основной текст #1D1F23, вторичный #60646C.
- Один основной синий акцент #0066CC. Stop/ошибка #BE2B27; успех — спокойный зелёный. Текст и значок дублируют цвет статуса.
- Нативные кнопки имеют радиус 8 DIP и внешнее кольцо focus; поверхности 10 DIP. Логическая прямоугольная область клика сохраняется. WPF масштабирует DIP под DPI.
- Отступы 8/12/14, спокойная иерархия, обычный регистр надписей. Hover/pressed меняют opacity без движения hit target.
- Tab, Enter, Space и Windows UI Automation сохраняются нативными Button. High contrast использует системные кисти.
- Код/ошибки/результаты доступны для копирования. Send превращается в Stop; при пустом каталоге отправка выключена.
- Настройки остаются отдельным диалогом; действия подключения разделены на две короткие строки.

Не требуются SF Pro, веб-шрифты, blur, CDN или новый стек. Узкая панель и DPI 100/125/150/200% требуют отдельной проверки в Rhino; факт проверок указан в TEST_REPORT.md.
