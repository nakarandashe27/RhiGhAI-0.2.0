# Проактивность без самоуправства

RhiGhAI самостоятельно:

- обновляет состояние Codex и список поддерживаемых моделей;
- собирает свежий snapshot документа;
- откатывает неудачную попытку;
- передаёт диагностическую ошибку обратно Codex и повторяет до заданного лимита;
- открывает Grasshopper и создаёт пустой definition, когда выбран Grasshopper target.

RhiGhAI не должен самостоятельно:

- устанавливать или обновлять runtime без явного действия пользователя;
- менять геометрию, не относящуюся к запросу, выделению или ownership разговора;
- продолжать после смены target, stale fingerprint, auth/usage ошибки или Stop;
- расширять allowlist либо обходить валидатор ради «полезного» результата.
