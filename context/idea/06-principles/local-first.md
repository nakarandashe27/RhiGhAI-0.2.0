# Local-first

- Исходная геометрия и полная структура документа остаются в Rhino.
- Codex получает только промпт, компактный структурированный snapshot единиц, слоёв, выделения, типов и разрешённых ownership-ссылок.
- Авторизацию и токены хранит официальный Codex runtime; RhiGhAI не просит API-ключ и не копирует учетные данные.
- Диалог и соответствие document ↔ Codex thread хранятся локально в профиле пользователя, но thread id и история не записываются в файл 3dm.
- Плагин не сканирует посторонние файлы, сеть или процессы; установка Codex выполняется только явной кнопкой.

Local-first здесь означает минимизацию передаваемого контекста и сохранение контроля в host, а не автономную работу модели без интернета.
