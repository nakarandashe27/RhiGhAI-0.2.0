# Реалистичный продукт для одного разработчика

MVP рассчитан на одного пользователя Windows x64, Rhino 8.20+ и Grasshopper 1. Это сознательное ограничение поддержки.

- Не строить SaaS, собственную авторизацию, биллинг или телеметрию.
- Использовать официальный Codex runtime и RhinoCommon/Grasshopper SDK, изолируя нестабильный app-server адаптером.
- Поставлять локальный installer first; Yak готовить после проверки на реальной машине и решения signing/distribution.
- Поддерживать небольшой capability registry вместо обещания «всё, что умеет Rhino».
- Автоматизировать schema, validator и transaction tests прежде расширения операций.
- Считать совместимость и установку частью продукта: первая установка должна быть воспроизводимой без Visual Studio и ручного редактирования файлов.

Это удерживает [[../04-mvp/scope]] выполнимым и превращает ограничения в надёжность.
